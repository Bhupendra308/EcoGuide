# ♻️ EcoGuide

A responsive React application that helps users understand household waste classification and discover practical upcycling ideas. Built as an educational project using React and Vite.

## Features

- ♻️ Waste classification (Recyclable, Compost, Landfill)
- 📖 Educational information about waste disposal
- 🎨 Upcycling ideas for common household items
- 📱 Responsive design
- ⚡ Fast performance with Vite

## Tech Stack

- React
- Vite
- JavaScript
- CSS


## Getting Started

Clone the repository:

```bash
git clone https://github.com/Bhupendra308/EcoGuide.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
